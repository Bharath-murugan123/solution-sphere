# Solution Sphere — product and UI direction

## Design intent
The interface is intentionally restrained and editorial: warm off-white canvas, dark green actions, sage panels, compact labels, and consistent spacing. It avoids oversized gradient headlines, decorative emoji, invented scale claims, and reward metrics that imply a mature network before evidence exists.

## Content principles
- Describe what the platform currently lets a user do: browse challenges, save opportunities, apply, and manage a profile.
- Do not publish unverified counts for members, companies, rewards, or impact.
- Mark seeded challenge listings and application counts as sample data.
- Use specific, plain-language labels and avoid hype such as “next-gen” or “revolutionary”.
- Treat achievements as lightweight activity indicators rather than an invented reputation currency.

## Colour tokens
- Canvas: `#F6F6F0`
- Surface: `#FFFEFA`
- Sage surface: `#E9EEE4`
- Primary action: `#174B38`
- Accent: `#24634D`
- Main text: `#202A24`
- Muted text: `#737B70`
- Border: `#E1E3D9`

This is an original visual direction informed by the restraint and neutral surfaces common in professional product interfaces, not a copy of another platform.
